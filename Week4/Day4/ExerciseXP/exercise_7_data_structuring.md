
# Exercise 7: Transforming Unstructured Data into Structured Data

## 1. Travel Blog Posts

Travel blog posts contain free-form text about destinations,
experiences, hotels, restaurants, and activities.

To structure this data:
- Extract destination names, countries, and cities.
- Identify travel dates and trip durations.
- Extract mentions of hotels, restaurants, and attractions.
- Use sentiment analysis to classify positive or negative experiences.
- Store the extracted information in a table.

Example columns:
Destination, Country, TravelDate, Hotel, Rating, Sentiment

## 2. Customer Service Audio Recordings

Customer service recordings contain spoken conversations
between customers and support representatives.

To structure this data:
- Convert audio recordings into text using speech-to-text.
- Identify customer issues and request categories.
- Extract call duration and resolution status.
- Analyze customer sentiment.
- Store the results in a database or spreadsheet.

Example columns:
CallID, Date, Duration, IssueCategory, Sentiment, Resolved

## 3. Handwritten Brainstorming Notes

Handwritten notes contain ideas, sketches, and free-form text.

To structure this data:
- Scan or photograph the notes.
- Use Optical Character Recognition (OCR) to extract text.
- Group ideas into categories or themes.
- Identify action items and priorities.
- Organize the information in a table.

Example columns:
NoteID, Idea, Category, Priority, ActionRequired

## 4. Cooking Tutorial Videos

Cooking videos contain visual and spoken instructions.

To structure this data:
- Transcribe spoken instructions into text.
- Identify ingredients and quantities.
- Extract cooking steps and preparation times.
- Categorize recipes by cuisine or meal type.
- Store the information in a structured dataset.

Example columns:
RecipeName, Ingredient, Quantity, CookingTime, Step, Cuisine

## Conclusion

Unstructured data can be transformed into structured
data using techniques such as OCR, speech-to-text,
natural language processing, and information extraction.

Once organized into rows and columns, the information
can be analyzed using Python, Pandas, SQL, or Excel.
