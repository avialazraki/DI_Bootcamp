
# Exercise 6: Structured vs. Unstructured Data

## Data Classification

| Data Example | Classification | Explanation |
|---|---|---|
| Excel spreadsheet containing financial reports | Structured | Financial information is organized into rows and columns, making it easy to filter, calculate, and analyze. |
| Collection of photographs | Unstructured | Images contain visual information without a predefined tabular format. |
| News articles | Unstructured | Articles contain free-form text that does not follow a fixed database structure. |
| Relational database containing inventory information | Structured | Inventory records follow a predefined schema with fields such as product ID, quantity, and price. |
| Recorded customer interviews | Unstructured | Audio recordings contain spoken information that must be transcribed or processed before traditional tabular analysis. |

## Summary

Structured data follows an organized format and can
usually be analyzed directly using tools such as
SQL, Excel, or Pandas.

Unstructured data includes images, audio, and free-form
text. It often requires additional processing before
useful information can be extracted.

Both types of data are valuable for business analysis.
