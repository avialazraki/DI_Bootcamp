
# Exercise 5: Exploring the Sleep Dataset

## Interesting Columns for Analysis

The "How Much Sleep Do Americans Really Get?" dataset contains
945 records and 9 columns.

The following columns are particularly useful for analysis:

| Column | Why It Is Interesting |
|---|---|
| Year | Helps identify changes in sleeping habits over time. |
| Avg hrs per day sleeping | The main measurement used to analyze sleep duration. |
| Age Group | Allows comparison of sleeping patterns between age groups. |
| Sex | Allows comparison of average sleeping hours across demographic groups. |
| Type of Days | Helps investigate differences between weekdays, weekends, and other day categories. |
| Standard Error | Helps evaluate the uncertainty of the estimated average sleeping hours. |

## Potential Analysis Questions

1. Has average sleeping time changed over the years?
2. Which age groups report the highest and lowest average sleeping hours?
3. Are there differences in sleeping duration between sexes?
4. Do people sleep longer on weekends than on weekdays?
5. How reliable are the reported averages based on their standard errors?

## Conclusion

The most important column is "Avg hrs per day sleeping"
because it provides the main quantitative measurement.

By combining this column with Year, Age Group, Sex,
and Type of Days, we can investigate trends and
differences in sleeping habits across population groups.
