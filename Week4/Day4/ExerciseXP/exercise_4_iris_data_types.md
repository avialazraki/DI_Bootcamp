
# Exercise 4: Identifying Data Types in the Iris Dataset

## Dataset Overview

The Iris dataset contains 150 observations and 6 columns.
It includes measurements of iris flowers and their species.

## Column Classification

| Column | Classification | Explanation |
|---|---|---|
| Id | Identifier | Unique row identifier, not a measurement. |
| SepalLengthCm | Quantitative (continuous) | Measures sepal length in centimeters. |
| SepalWidthCm | Quantitative (continuous) | Measures sepal width in centimeters. |
| PetalLengthCm | Quantitative (continuous) | Measures petal length in centimeters. |
| PetalWidthCm | Quantitative (continuous) | Measures petal width in centimeters. |
| Species | Qualitative (nominal) | Identifies the flower species. |

## Summary

The dataset contains:

- 4 quantitative columns representing flower measurements.
- 1 qualitative column representing flower species.
- 1 identifier column used to distinguish records.

The quantitative columns can be used for statistical
calculations such as averages and comparisons.

The qualitative Species column can be used to group
flowers by category and compare their measurements.

All 150 records have complete data.
