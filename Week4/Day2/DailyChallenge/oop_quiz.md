
# Week 4 Day 2 - Daily Challenge
## Exercise 1: OOP Quiz

### 1. What is a class?
A class is a blueprint for creating objects. It defines the attributes
(data) and methods (functions) that its objects can have.

### 2. What is an instance?
An instance is an individual object created from a class.
For example, if Dog is a class, my_dog = Dog() creates an instance.

### 3. What is encapsulation?
Encapsulation means grouping data and methods together inside a class
and controlling how the object's internal data is accessed or modified.

### 4. What is abstraction?
Abstraction means hiding unnecessary implementation details and
showing only the essential functionality to the user.

### 5. What is inheritance?
Inheritance allows a class to reuse and extend the attributes and
methods of another class.

### 6. What is multiple inheritance?
Multiple inheritance allows a class to inherit from more than one
parent class.

### 7. What is polymorphism?
Polymorphism means that different objects can use the same method
name but implement different behaviors.

### 8. What is method resolution order (MRO)?
MRO is the order Python follows when searching for a method or
attribute in a class and its parent classes.
Python uses the C3 linearization algorithm to determine this order.
We can inspect it using ClassName.mro().
